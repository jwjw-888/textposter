# 文字海报

输入文字，选背景模板，一键生成小红书风格的文字图片（PNG）。

- 纯前端，单个 `index.html`，不需要服务器，也不上传任何文字
- 10 种背景模板，3 种尺寸（3:4 / 1:1 / 9:16）
- 黑体 / 宋体 / 楷体，字号、行距、对齐、颜色可调
- 字多时自动分页，可加日期、页码
- 底色可选色或用调色盘自订（底色太深会自动换浅色字）
- 附带 5 种免费字体（文楷、快乐体、小薇、毛笔、手写，均为 SIL OFL 授权，见 `fonts/OFL.txt`），选到时才下载
- 可上传自己的字体（.ttf / .otf / .woff / .woff2），存在自己的浏览器里，不会上传到网络

## 部署

网站文件都在 `public/`，用 Cloudflare Workers 发布（设定在 `wrangler.jsonc`）。
- 标题可单独设定字体、字号、颜色、标示笔颜色
- 正文选取文字后按「马克笔 强调」可加马克笔底色（文字前后会加上 `__`），颜色可调
- 可安装成手机 App（PWA）：Android 按网页上的「安装 App」，iPhone 用 Safari 分享 →「加入主画面」；装好后没网络也能用
- 原始 icon 图档：`icon-original.png`（各尺寸 icon 在 `public/icons/`）
